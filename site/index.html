Un modelo vivo del sistema. Cinco notaciones para mirarlo.

No es un editor de diagramas: es un grafo con semántica. La misma caja es un agregado en la vista DDD, un contenedor en el C4 y una entidad en el MER — y cada vista sabe qué notación habla. Encima, una IA que corre en tu máquina razona sobre ese modelo y lo documenta.

El mismo sistema, cinco lecturas

DDDQué pasa en el negocio: eventos, comandos, agregados, políticas.
BPMNQuién hace qué y en qué orden: pools, tareas, gateways.
C4Con qué piezas está construido: sistemas, contenedores, componentes.
UMLCómo se habla por dentro: clases, estados, secuencias.
MERQué datos quedan: entidades, atributos, cardinalidades.

Las notaciones salen de un registro único (src/lib/notations.ts): la paleta, la validación y la IA leen de ahí. Agregar una notación no toca el lienzo.

Un solo modelo

Las vistas no se desincronizan entre sí

El C4 y el diagrama de procesos no son dos archivos que alguien tiene que acordarse de actualizar: son dos lecturas del mismo grafo. Hasta 50 vistas, y las que importan se inyectan al chat del agente en vez de darle el modelo entero.

Semántica

Cada notación con su gramática, desde un registro único

src/lib/notations.ts es la única fuente de verdad de los tipos. En una vista BPMN la IA propone tareas y gateways; en una C4, contenedores. Nada de cajas genéricas con texto adentro.

Trazabilidad

Cada caja dice de dónde salió

Ficha por elemento: descripción, especificación y criterios. Adjuntás el documento fuente al proyecto y la cita de una caja resuelve al fragmento exacto que la originó. Los artefactos del agente son versionados y guardan su historial.

Privacidad

El modelo nunca sale del equipo

La inferencia corre en tu GPU con LiteRT-LM sobre WebGPU: cero llamadas a la nube por defecto. Es la diferencia entre poder usar IA sobre el core de un banco o de una EPS, y no poder. Si activás un proveedor remoto, la llave se guarda cifrada con safeStorage en el proceso principal: nunca llega al renderer ni a los logs.

Offline

Funciona en un avión y en una sala sin wifi

Descargás el modelo una vez. Después el trabajo no depende de la red, de una cuota de tokens ni de que el proveedor tenga un mal día — y no hay factura por token.

Interoperable

Entra por MCP, sale como texto

Claude Code y Codex construyen el modelo desde tus documentos o tu código y lo exportan al lienzo. De vuelta salen Mermaid, Markdown estructurado y PDF: cosas que viven en el repo y se revisan en un PR.

Robustez

El lienzo nunca queda en blanco

Si un filtro vacía el resultado, el procesador vuelve a la vista general e incluye los nodos sueltos. Es un principio con prueba en el gate, no una buena intención.

Una vista, una notación

Las cinco gramáticas.

NotaciónPara quéElementos típicos
DDDDominio: vista general y diseño tácticoEvento · Comando · Agregado · Política · Read Model · Sistema Externo
BPMNProcesos de negocioPool · Tarea · Gateway · Subproceso (call activity)
C4Paisaje de sistemasPersona · Sistema · Contenedor · Componente
UMLEstructura e interacciónClase · Interfaz · Caso de uso · Estados · Secuencia (línea de vida + mensaje)
MERDatosEntidad · Atributo · Relación con cardinalidad

En UML el tipo de relación lo dice la punta: flecha (asociación), triángulo hueco (herencia), triángulo punteado (realización), rombo relleno (composición), rombo hueco (agregación) y punteada con flecha (dependencia).

De cero a un modelo

Empezar.

Instalá el binario o cloná el repo

En Releases hay .dmg (Apple Silicon), instalador .exe y .AppImage. Para el modo desarrollo: Node 20+ y una GPU con WebGPU, obligatoria para la IA local.

git clone https://github.com/raalzate/processflow-architect
cd processflow-architect
npm install
npm run electron-dev

Descargá un modelo, una sola vez

En Ajustes elegís el .litertlm. A partir de ahí la IA funciona sin conexión.

Traé el material: sesión, documento o repo

Modelás a mano en el lienzo, o conectás Claude Code por MCP y le pedís que construya el modelo desde tus fuentes y lo exporte al lienzo.

Derivá vistas, preguntá, exportá

Las vistas se abren en pestañas y los artefactos del agente quedan versionados al lado del lienzo. Cuando sirven, salen como Mermaid, Markdown o PDF y se van al repo con el resto de la documentación.
