## Processflow Architect 0.22.1 · beta

Release de arreglos sobre 0.22.0: las organizaciones ya no esconden el proyecto en el que estás trabajando, y el tema claro vuelve a dejar leer el texto al pasar el mouse.

### Cambios

- **El proyecto nuevo nace en la organización que estás mirando.** Con una organización elegida en el header, crear un proyecto (o importar un tablero o un diagrama) lo dejaba sin organización: el filtro lo escondía y el selector decía «Sin proyectos en …» con el proyecto abierto en el lienzo. Ahora queda dentro de esa organización.
- **El selector siempre muestra el proyecto abierto.** Aunque el filtro de organización lo deje afuera, el selector lo nombra en vez de anunciar una lista vacía.
- **Crear un proyecto lo abre.** Si la galería de la organización estaba a la vista, el proyecto recién creado quedaba debajo y no se veía seleccionado.
- **El hover del tema claro ya no borra el texto.** Botones, menús y fichas de la paleta pintaban un fondo medio sobre el que el texto atenuado y los íconos casi desaparecían. El hover ahora es un tinte suave con texto oscuro.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.22.1-arm64.dmg` |
| Windows | `Processflow-Architect.Setup.0.22.1.exe` |
| Linux | `Processflow-Architect-0.22.1.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.22.1.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. El proveedor de nube es opcional, apagado por defecto y con tu propia llave,
que se guarda cifrada y nunca sale del proceso principal.
