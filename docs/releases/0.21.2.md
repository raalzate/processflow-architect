## Processflow Architect Collab 0.21.2 · beta

### Cambios

- Las solicitudes de fusión incorporan vistas nuevas a Principal aunque esas vistas solo existan en la rama de origen. La corrección también se aplica a solicitudes que ya estaban pendientes.
- Traer cambios de otra rama admite vistas nuevas y conserva las ediciones independientes del destino.

### Descargas

En Windows, ejecuta `Processflow-Architect-Collab-Setup-0.21.2.exe`. El instalador conserva los datos del perfil al actualizar la beta.

### Requisitos

El instalador de Windows de esta beta es para equipos x64.
