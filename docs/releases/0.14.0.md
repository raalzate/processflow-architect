## Processflow Architect 0.14.0 · beta

Esta versión hace que actualizar la app sea un solo clic, suma **OpenRouter** como
proveedor de IA en la nube y cierra varias puertas de seguridad que estaban abiertas en la
app instalada. La IA sigue siendo local por defecto: nada de esto cambia si no lo activás.

### Cambios

- **Actualizar es un solo clic (#467).** Al pulsar «Actualizar», la app descarga la versión
  nueva, se cierra, se instala y vuelve a abrirse. Antes, en macOS el instalador quedaba en
  Descargas para arrastrarlo a mano, y en Windows y Linux hacía falta un segundo clic. Si
  algo falla en macOS, el instalador se abre como antes y queda en Descargas.
- **OpenRouter como proveedor de IA en la nube (#470).** En Ajustes → IA remota hay una
  cuarta opción, junto a Gemini, OpenAI y Anthropic. Con una sola llave de OpenRouter podés
  elegir entre muchos modelos (Gemini, GPT, Claude, Llama…). La llave se guarda cifrada en tu
  equipo, como las demás, y nunca llega a la ventana de la app.
- **Más segura por dentro (#472).**
  - La app instalada ahora aplica la política de mismo origen del navegador, que estaba
    apagada.
  - La app ya no concede cualquier permiso que se le pida: sólo el portapapeles. Cámara,
    micrófono y ubicación quedan negados.
  - Una política de contenido (CSP) impide ejecutar código o conectarse a sitios ajenos.
    Sólo se permiten tus modelos locales y el CDN de donde salen las librerías de IA.
  - El repositorio tiene política de seguridad (`SECURITY.md`) con un canal privado para
    reportar vulnerabilidades, y avisos automáticos de dependencias vulnerables.
- **Preparada para lo que viene (#470).** La app ya no depende de Electron en cada
  pantalla: habla con el sistema por un único punto. No cambia nada de lo que ves, pero es
  la base para una futura versión web.
- **El pie de créditos enlaza al repositorio (#467)** en lugar de un correo personal.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.14.0-arm64.dmg` |
| Windows | `Processflow-Architect-Setup-0.14.0.exe` |
| Linux | `Processflow-Architect-0.14.0.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.14.0.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. Sin ella la app sigue sirviendo para diseñar, importar, exportar y servir MCP; si
querés sugerencias o el agente constructor, activá un proveedor de IA en la nube en Ajustes
(Gemini, OpenAI, Anthropic u OpenRouter), con tu propia llave, que se guarda cifrada y nunca
sale del proceso principal. Para usar Claude Code en el chat o como motor, instalalo y entrá
con tu cuenta en una terminal (`claude`); la app usa esa sesión.
