## Processflow Architect 0.16.0 · beta

Esta versión le da **voz** al agente: cada respuesta se puede escuchar en español, con un
modelo que corre en tu equipo. Suma un **indicador de consumo** de la IA local y arregla las
respuestas que aparecían como JSON crudo cuando la ventana del motor local se llenaba. La IA
sigue siendo local por defecto: nada de esto cambia si no lo activás.

### Cambios

- **Escuchar las respuestas del agente (#605).** Cada respuesta del agente tiene un botón
  «Escuchar» que la lee en voz alta en español con Kokoro. En Ajustes → **Voz** elegís la
  voz (Dora, Alex o Santa), la velocidad (pausada, normal o rápida), la probás y borrás el
  modelo cuando quieras. El modelo (~90 MB) se descarga una vez; la síntesis corre aparte
  para no congelar la ventana ni quitarle la GPU al motor de IA. No lee bloques de código,
  pasa los números a palabras y empieza a hablar con la primera frase.
- **Indicador de consumo de la IA local (#602).** Junto al botón del MCP, un chip con
  semáforo muestra la CPU del equipo y la memoria de la app; el tooltip suma la memoria del
  proceso de GPU, donde vive el modelo. Aparece sólo en los modos local e híbrido.
- **Respuestas cortadas ya no salen como JSON (#601).** Con la IA local, tras varios pasos
  la ventana del motor se llenaba y el chat mostraba un `{"thought":…` a medio cerrar. Ahora
  el agente rescata un plan con lo que ya leyó o avisa que la ventana se llenó, con el botón
  para ampliarla.
- **Dependencias al día (#607, #608, #609, #610).** React 19.3.1, Next 15.5.28, Mermaid
  12.2, Puppeteer 25.14 y los componentes de Radix.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.16.0-arm64.dmg` |
| Windows | `Processflow-Architect-Setup-0.16.0.exe` |
| Linux | `Processflow-Architect-0.16.0.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.16.0.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. Sin ella la app sigue sirviendo para diseñar, importar, exportar y servir MCP; si
querés sugerencias o el agente constructor, activá un proveedor de IA en la nube en Ajustes
(Gemini, OpenAI, Anthropic u OpenRouter), con tu propia llave, que se guarda cifrada y nunca
sale del proceso principal. Para usar Claude Code en el chat o como motor, instalalo y entrá
con tu cuenta en una terminal (`claude`); la app usa esa sesión.
