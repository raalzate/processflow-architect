## Processflow Architect 0.6.1 · beta

Release de créditos y de mudanza: **no hay cambios funcionales** en el lienzo, las
vistas ni la IA. Si venís de 0.6.0, actualizar es opcional.

### Cambios

- **Créditos de autoría.** La app acredita a Raúl Andrés Alzate Gómez
  (alzategomez.raul@gmail.com): el nombre en la cabecera, el crédito con el correo
  en el pie del panel y en «Acerca de». Fuera el logo anterior. El clic en el correo
  ahora abre el cliente de mail del sistema (`mailto:` antes no hacía nada).
- **Capturas del README rehechas** contra la UI actual.
- **Repositorio nuevo:** el proyecto vive en `raalzate/processflow-architect`. El
  `git clone` del README y el empaquetado apuntan ahí.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.6.1-arm64.dmg` |
| Windows | `Processflow-Architect.Setup.0.6.1.exe` |
| Linux | `Processflow-Architect-0.6.1.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.6.1.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. El proveedor de nube es opcional, apagado por defecto y con tu propia llave,
que se guarda cifrada y nunca sale del proceso principal.
