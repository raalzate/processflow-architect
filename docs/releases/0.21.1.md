## Processflow Architect Collab 0.21.1 · beta

### Cambios

- Las salas tienen un cupo base de cinco personas, incluido el anfitrión. El cupo puede crecer según el equipo y las rutas de conexión.
- El menú de exportación permite descargar todas las vistas del proyecto en un ZIP con archivos SVG, PNG o HTML.
- El instalador de Windows reemplaza una instalación anterior de Processflow Architect Collab y conserva el perfil con los proyectos y ajustes.

### Descargas

En Windows, ejecuta `Processflow-Architect-Collab-Setup-0.21.1.exe`. Windows puede mostrar un aviso porque el instalador de esta beta carece de firma digital.

### Requisitos

La compilación de Windows de esta beta es para equipos x64. El diseño y la exportación funcionan sin WebGPU. La IA local necesita una GPU con WebGPU y la IA remota requiere una clave propia.
