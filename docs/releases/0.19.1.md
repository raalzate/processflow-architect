## Processflow Architect 0.19.1 · beta

Corrección del agente del chat: una pregunta sobre el proyecto se contesta, en vez de
convertirse en un plan para generar un artefacto. Se recomienda actualizar si usás el chat
con IA local. La IA sigue siendo local por defecto.

### Cambios

- **Preguntar ya no dispara un artefacto.** «¿De qué se trata la propuesta?» terminaba en un
  plan para generar una «Síntesis de la Propuesta», porque bastaba con nombrar un artefacto
  (propuesta, documento, diagrama, C4, BPMN…) para que el agente quisiera generarlo. Ahora
  hace falta pedirlo: «generá la propuesta», «¿me armás el roadmap?» o el botón «+». Las
  preguntas, las explicaciones y los resúmenes se contestan.
- **El agente lee las vistas para contestar.** Una pregunta puede necesitar una vista que no
  está abierta: el agente la lee y contesta citando de dónde sale, sin proponer planes ni
  dejar nada en el lienzo. Antes sólo veía el diagrama activo y los nombres de las demás vistas.
- **El agente recuerda la conversación.** Una repregunta («¿y eso qué implica?») llega con los
  últimos mensajes del chat. Antes cada mensaje se respondía como si fuera el primero.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.19.1-arm64.dmg` |
| Windows | `Processflow-Architect-Setup-0.19.1.exe` |
| Linux | `Processflow-Architect-0.19.1.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.19.1.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. Sin ella la app sigue sirviendo para diseñar, importar, exportar y servir MCP; si
querés sugerencias o el agente constructor, activá un proveedor de IA en la nube en Ajustes
(Gemini, OpenAI, Anthropic u OpenRouter), con tu propia llave, que se guarda cifrada y nunca
sale del proceso principal. Para usar Claude Code en el chat o como motor, instalalo y entrá
con tu cuenta en una terminal (`claude`); la app usa esa sesión.
