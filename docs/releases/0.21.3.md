## Processflow Architect Collab 0.21.3 · beta

### Cambios

- Las copias compartidas vuelven a conectarse aunque su historial guardado supere los 32 MiB.
- El botón **Reconectar** permite adelantar el intento cuando se pierde el vínculo con el anfitrión. Los reintentos automáticos siguen activos.

### Descargas

En Windows, ejecuta `Processflow-Architect-Collab-Setup-0.21.3.exe`. El instalador conserva los datos del perfil al actualizar la beta.

### Requisitos

El instalador de Windows de esta beta es para equipos x64.
