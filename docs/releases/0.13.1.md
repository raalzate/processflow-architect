## Processflow Architect 0.13.1 · beta

Esta versión conecta la ficha de cada elemento con agentes de IA. Desde el nuevo tab
**«Agente»** podés conversar sobre la caja que tenés abierta y pedir que se pula su
especificación. Contesta la IA de la app o, si lo tenés instalado, **Claude Code**, que
puede leer las carpetas que le adjuntes y escribir la spec en la caja. Además, Claude Code
puede ser el motor de toda la IA de la app, con un tope de gasto que vos elegís. Todo es
opcional: por defecto sigue la IA local. Si venís de la 0.12.0, esta es la actualización: la
0.13.0 no se publicó y todo lo suyo viene acá.

### Cambios

- **Tab «Agente» en la ficha del elemento (#444, #459).** Un chat sobre la caja abierta.
  Por defecto contesta la IA de la app con el motor que elegiste en Ajustes. Si tenés
  **Claude Code** instalado, podés elegirlo: lee la ficha entera, te muestra su propuesta y,
  cuando la aprobás, escribe la especificación directamente en la caja; la ves aparecer en
  el tab Spec. Las respuestas se muestran con formato, y la papelera empieza una
  conversación nueva. Codex aparece como «(pronto)»: se habilita cuando esté verificado.
- **Adjuntar una carpeta como contexto (#460).** Con el ícono de carpeta del chat elegís
  una carpeta de tu equipo (código, contratos, documentación) y Claude Code la usa para
  pulir la caja, citando de qué archivo sacó cada cosa. Sólo la lee: no puede escribir ni
  ejecutar nada ahí, y sólo valen las carpetas que elegiste con ese botón.
- **Claude Code como motor de la IA (#451).** En Ajustes → Motor de IA hay una cuarta
  opción, «Claude Code». Las sugerencias de la ficha, las tareas de IA y el Constructor
  razonan con tu Claude Code, con tu propia sesión y sin llaves guardadas en la app; lo que
  se escribe en el lienzo lo sigue haciendo la app con sus confirmaciones. Cada sugerencia
  tarda unos segundos más y la factura tu cuenta de Claude.
- **Tope de gasto de Claude Code (#462).** Ajustes muestra cuánto llevás gastado en la sesión
  y te deja fijar un tope (US$ 5 por defecto) o quitarlo. Al llegar al tope, la app deja de
  llamar a Claude Code y te lo dice, en vez de seguir sumando en tu factura.
- **Integración con agentes externos por MCP (#433).** Un agente externo (Claude Code u
  otro cliente MCP) sabe qué caja tenés abierta, la lee entera en una llamada y escribe su
  especificación donde la ves. El botón con forma de enchufe en la ficha enciende el
  servidor MCP y copia un prompt listo para pegar. Nuevo skill instalable `pulir-elemento`.
- **Más seguro por defecto (#461, #462).** El agente del chat sólo puede leer la caja y
  escribir la spec de ESA caja: nada que borre o reemplace vistas, ni la spec de otra caja.
  El servidor MCP rechaza conexiones que no vengan de tu propio equipo, y el que enciende el
  chat no queda activado para siempre; eso se decide en Ajustes.
- **Más robusto con Claude Code (#462).** Funcionan los pedidos con mucho contexto y los
  que empiezan con un guion; la app encuentra Claude Code aunque lo hayas instalado con nvm;
  te avisa si está instalado pero sin sesión iniciada; y al cerrar la app no queda ningún
  proceso del agente corriendo.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.13.1-arm64.dmg` |
| Windows | `Processflow-Architect-Setup-0.13.1.exe` |
| Linux | `Processflow-Architect-0.13.1.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.13.1.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. Sin ella la app sigue sirviendo para diseñar, importar, exportar y servir MCP; si
querés sugerencias o el agente constructor, activá un proveedor de IA en la nube en Ajustes,
con tu propia llave, que se guarda cifrada y nunca sale del proceso principal. Para usar
Claude Code en el chat o como motor, instalalo y entrá con tu cuenta en una terminal
(`claude`); la app usa esa sesión. En Windows sólo se detecta la instalación nativa
(`claude.exe`) y todavía no está verificado.
