## Processflow Architect 0.19.0 · beta

Esta versión hace que cada caja se vea y se complete según lo que ES: el logo de su
tecnología sale solo de las etiquetas (y ahora hay casi el doble de logos, incluidos OpenAI,
Bedrock y Railway), una base de datos pide sus propios datos y no un repositorio, y el nombre
y la descripción se editan con doble clic sobre el lienzo. El chat del agente en la ficha
ofrece pedidos de ejemplo, deja elegir el modelo y lo que escribe aparece al momento. La IA
sigue siendo local por defecto.

### Cambios

- **Propiedades según el tipo de elemento (#643).** La tabla «Referencias» sugiere lo que le
  falta a ESA caja: a un servicio, `repo`, `puerto` y `endpoint`; a una base de datos,
  `puerto`, `motor`, `esquema` y `respaldo` (ya no se le exige repositorio). Lo que ya está
  —también con otro nombre, como `port`— no se vuelve a proponer.
- **288 iconos de tecnología (#643).** El catálogo casi se duplica: Railway, Render, Fly.io,
  OpenAI, Amazon Bedrock, Groq, Vertex AI, Ollama, Claude, Neon, DynamoDB, FastAPI, NestJS,
  OpenTelemetry y más. Para AWS Lambda y S3, que no tienen logo libre, hay iconos genéricos
  («Función serverless», «Almacenamiento de objetos»).
- **El logo sale de las tecnologías (#643).** Si una caja dice `Node 20` o `PostgreSQL 16` y
  nadie le eligió icono, se le pone el logo que corresponde, también cuando la crea o la
  actualiza un agente por MCP. Un icono elegido a mano nunca se pisa. La ficha ofrece «Usar
  Node.js» cuando lo detecta.
- **Logo grande y legible en la caja (#643).** El logo va a la izquierda, a buen tamaño y sobre
  una pastilla clara, así los logos oscuros (.NET, OpenAI) se distinguen sobre la caja.
- **Doble clic para editar en el lienzo (#643).** Doble clic sobre el nombre o la descripción
  los edita ahí mismo (Enter guarda, Esc cancela, ⌘Z deshace); en el resto de la caja sigue
  abriendo la ficha.
- **Flujo animado en las relaciones (#643).** La relación seleccionada, y las de la caja
  seleccionada, muestran guiones que corren hacia el destino.
- **Tab Agente más útil (#643).** Botones con pedidos de ejemplo según el tipo de caja,
  selector de modelo para Claude Code (Sonnet, Opus, Haiku o el tuyo) y el agente ahora puede
  completar tecnologías, icono y referencias de la caja abierta, no sólo su spec.
- **Lo que escribe el agente aparece al momento (#643).** Antes la ficha seguía mostrando la
  versión de cuando se abrió y había que recargar con Ctrl+R.
- **La ficha no tapa el diagrama (#643).** Con la ficha abierta el lienzo se puede desplazar
  más a la derecha, para traer a la vista lo que quedaba debajo. Al ensanchar la ficha,
  «Icono» pasa a la columna izquierda y ya no deja un hueco.

### Descargas

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon) | `Processflow-Architect-0.19.0-arm64.dmg` |
| Windows | `Processflow-Architect-Setup-0.19.0.exe` |
| Linux | `Processflow-Architect-0.19.0.AppImage` |

Los binarios **no están firmados con certificado de confianza**, así que la primera
apertura muestra un aviso:

- **macOS:** clic derecho sobre la app → **Abrir**. Si el navegador dejó cuarentena:
  `xattr -cr /Applications/Processflow-Architect.app`
- **Windows:** SmartScreen → **Más información** → **Ejecutar de todas formas**.
- **Linux:** `chmod +x Processflow-Architect-0.19.0.AppImage` y ejecutalo.

### Requisitos

GPU con **WebGPU**: la IA corre local y offline (LiteRT-LM sobre WebGPU) y sin GPU no
arranca. Sin ella la app sigue sirviendo para diseñar, importar, exportar y servir MCP; si
querés sugerencias o el agente constructor, activá un proveedor de IA en la nube en Ajustes
(Gemini, OpenAI, Anthropic u OpenRouter), con tu propia llave, que se guarda cifrada y nunca
sale del proceso principal. Para usar Claude Code en el chat o como motor, instalalo y entrá
con tu cuenta en una terminal (`claude`); la app usa esa sesión.
